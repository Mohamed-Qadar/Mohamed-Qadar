## Professional Profile

I am a Computer Engineer with an M.Sc. from Fırat University and a B.Sc. from Karadeniz Technical University, with experience spanning artificial intelligence, software engineering, cybersecurity, computer networks, and embedded systems.

My research focuses on Natural Language Processing, transformer-based models, low-resource language processing, Computer Vision, automatic question generation, biomedical NLP, Somali-language text classification, deepfake detection, and autonomous-driving computer vision.

Alongside research, I have hands-on experience developing backend services, RESTful APIs, database-driven platforms, real-time applications, browser automation tools, and embedded/IoT systems using C#, ASP.NET Core, Python, Node.js, React, SQL Server, PostgreSQL, Docker, and related technologies.

My cybersecurity work includes SOC architecture, vulnerability assessment, endpoint monitoring, web application hardening, threat intelligence, honeypots, and security monitoring.
